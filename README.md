# Caffè Italia · Marblehead website concept

An independent, responsive multi-page website concept for Caffè Italia Trattoria & Bar in Marblehead, Massachusetts. It uses the restaurant’s published location, phone number, menu categories, family background, catering offer, and hours. Reservation actions call the restaurant; this concept does not accept or transmit bookings.

## Run locally

```bash
npm install
npm run dev
```

Vite serves the site at `http://127.0.0.1:5175/`.

## Build for Vercel

Use the project folder as the Vercel root, set the build command to `npm run build`, and the output directory to `dist`.

The homepage cycles between two illustrative 4K stock clips—wine service at a bar and pasta being plated. They are not footage of Caffè Italia's premises or kitchen; the food photos are illustrative too. Video credits are in MEDIA-CREDITS.md. Bree Serif display text is paired with Lato body copy and navigation.

The official gallery does not identify when or where its room photos were taken. Since Caffè Italia moved to Bessom Street in 2025, confirm those photos still represent the current restaurant before publishing the concept publicly.
